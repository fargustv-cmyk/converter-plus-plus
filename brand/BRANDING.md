# Брендинг Converter++

## Логотипы

В этой папке два SVG-файла:

- **`logo-icon-512.svg`** — квадратная иконка 512×512 для аватара бота и иконки Mini App.
  Сине-фиолетовый градиент, схематичная цепочка из 3 валют, золотой бейдж "++" в углу.

- **`promo-640x360.svg`** — горизонтальный промо-баннер 640×360 для меню бота
  (Bot Settings → Bot Pic в @BotFather) и в галерее Mini Apps.

### Экспорт в PNG

@BotFather принимает PNG/JPG. Самый простой способ:
- Открыть SVG в Chrome / Edge → правый клик → «Сохранить как изображение»
- Или зайти на [cloudconvert.com/svg-to-png](https://cloudconvert.com/svg-to-png) — без регистрации, загрузить SVG, скачать PNG

Требования Telegram:
- Аватар бота: квадрат, минимум 512×512
- Bot Pic для меню: 640×360
- Иконка Mini App: квадрат

## Тексты

### Название (Bot Name)
```
Converter++
```

### Username бота (придумать свой, должен заканчиваться на `_bot`)
```
converter_plus_plus_bot
```
Если занят — попробовать `cnvrt_plus_bot`, `multistep_converter_bot`, `cppro_bot`.

### About text (короткая строка, видна в профиле бота, до 120 символов)
```
Конвертер валют с цепочкой ступеней. Курсы ЦБ РФ и крипта. Учитывает свой курс и комиссию банков/обменников.
```

🔗 Цепочка из нескольких валют
Не просто RUB → USD, а RUB → KZT → USD → KZT (например, для покупок в Steam через казахский аккаунт).

💱 Курсы ЦБ РФ + 300+ валют и криптовалют
Переключение между источниками одной кнопкой.

🔄 Двунаправленный ввод

⭐ Полная версия (разово, 100 Stars)

## Шрифт

**Inter** (Google Fonts) — основной шрифт интерфейса. Вес 400/500/600/700/800.

Для логотипа в SVG используется системный sans-serif fallback (`-apple-system, Segoe UI, Roboto`) — чтобы не зависеть от загрузки шрифта при рендере иконки.
